## Changed
- **Uses less battery.** The lyrics screen draws lines that hold still once instead of every frame, and work nobody can see now rests: the timeline while paused, videos and animated covers under ambient mode or the big cover, the moving background under the floating window's Canvas, scrolling names that are hidden, and the widget with the screen off or while the app covers it. Sources that are switched off are no longer warmed up
- **A slow source no longer holds a lookup up.** Each source request now gives up after 20 seconds, and matching a song on Spotify does less work per candidate
- **The source picker says "Still checking…"** next to sources that haven't answered yet, instead of "Not asked yet"

## Fixed
- **Animated covers missing for some songs** that only have one on their explicit edition
- **An update downloaded while the app was out of view** now shows a "tap to install" notification instead of waiting for the next time you open the app
- **TTML files** starting with a byte-order mark or spaces, or using `&nbsp;`, now load, and words with no end time, or one before their start, keep a length
- **Romanized syllables held over several letters** no longer split the letters in the wrong places
- **New lyrics no longer flash with the previous song's line states** for a frame
- **Turning Refined Credits or the pop-out on or off** takes effect right away
- **A manual Spotify ID** keeps its own lyrics, separate from the song's usual pick, and survives a player that sends the song length late. The widget checks it too
- The widget no longer looks up lyrics in the background with the screen off
- A half-typed custom source survives opening the floating window
- Importing a font the system can't describe no longer crashes
- Crashes are now recorded from every start of the app, not only from the lyrics screen
